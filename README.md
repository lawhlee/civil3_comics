# civil3_comics — 민법 판례 만화 서재

**공개 웹페이지: https://lawhlee.github.io/civil3_comics/**

민법 제6강부터 제10강까지 **271편**의 판례 만화입니다.

| 강의 | 편수 |
|---|---:|
| 제6강 공동소유와 명의신탁 | 91 |
| 제7강 담보물권과 저당권의 성립 | 23 |
| 제8강 저당권의 효력과 특수 저당권 | 89 |
| 제9강 유치권과 질권 | 31 |
| 제10강 가등기담보와 양도담보 | 37 |

강의별 목록, 제목·단원·판례번호 검색, 책갈피, 읽음 표시, 이어 읽기, 이전·다음 편 이동, 목차 및 이미지 확대를 지원합니다. 읽기 기록은 사용하는 브라우저에만 저장됩니다.

## 이미지와 업로드 방식

- 기존 교정 완료본의 **WebP 이미지 1,084개**를 그대로 보존합니다. 추가 손실 재압축이나 해상도 축소 없이 한글 글자와 교정 내용을 유지했습니다.
- 저용량 **480px**, 표준 **768px**, 고화질 **1024px**, 목록용 미리보기를 제공합니다. 기본값은 표준입니다. 작은 글씨는 고화질과 확대 기능으로 읽을 수 있습니다.
- 가장 큰 개별 이미지는 **599,882바이트**입니다. **Git LFS와 대용량 파일 저장 기능을 사용하지 않습니다.**
- 전체 정적 사이트를 추가 ZIP 압축한 **56개 묶음**으로 저장합니다. 각 묶음은 4MiB 이하이며, 전체는 **222,658,194바이트**입니다. WebP는 이미 압축되어 있으므로 ZIP의 추가 절감률은 작습니다.
- `asset-packs/manifest.json`에는 모든 ZIP 및 원본 파일의 크기와 SHA-256이 들어 있습니다. 빌드 시 경로, 중복, 크기, SHA-256, ZIP CRC 및 모든 활성 이미지 참조를 검사한 뒤에만 배포합니다.

## 로컬 실행

Python 3.10 이상만 필요합니다. 별도 설치나 서버 API가 없습니다.

```sh
python3 scripts/build-static.py
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. GitHub Pages는 같은 `dist`를 배포합니다. 파일 경로는 상대경로이므로 `/civil3_comics/` 하위 경로에서도 동작합니다.

## 수정과 검증

`dist`는 생성 결과라 Git에 넣지 않습니다. 웹페이지 동작 코드는 `site/app.js`에서 수정한 뒤 빌드합니다. 빌드는 ZIP의 원본 검증 후 이 코드만 적용하고, 내용 해시로 스크립트 URL을 갱신합니다. 이미지와 교정 내역은 원래 바이트를 유지합니다. 그 밖의 정적 파일은 수정한 뒤 아래처럼 다시 묶습니다.

```sh
python3 scripts/pack-static.py dist --out asset-packs
python3 scripts/build-static.py
```

묶음 수가 줄었다면 사용하지 않는 `part-*.zip`을 제거한 뒤 커밋합니다. `main`의 `asset-packs` 또는 빌드 스크립트 변경은 기존 GitHub Actions를 통해 공개 웹페이지에 반영됩니다.

## 원본 및 내용

기존 민법 판례 만화 서재 v5의 소스 커밋 `125c16886af45f58aea0d15c7dca203310a61e78`에서 가져왔습니다. 기존 Site는 변경하지 않았습니다. 73편의 83개 교정 항목과 나머지 198편을 그대로 보존합니다. 상세 교정 내역은 웹사이트 파일 `내용_교정내역.txt`, `텍스트_정정내역.txt`에 있습니다.

강의안의 인용 취지에 한정한 교육용 요약입니다.

## 브라우저 회귀 테스트

Node.js 24와 Python이 있는 환경에서 다음을 실행합니다.

```sh
python3 scripts/build-static.py
npm ci
npx playwright install --with-deps chromium webkit
npm test
```

테스트 서버는 GitHub Pages와 같은 `/civil3_comics/` 하위 경로로 실제 `dist`를 제공합니다. 데스크톱 Chromium·WebKit, Pixel 7 크기의 Chromium, iPhone 13 크기의 WebKit에서 확인합니다. 모바일 검사는 터치·화면 크기 에뮬레이션이며 실제 휴대폰 하드웨어 검사는 아닙니다.

- 목록 미리보기, 제목·한글·판례번호 검색, 강의 필터와 검색 결과 없음
- 저용량 480px·표준 768px·고화질 1024px의 실제 디코딩 크기와 화질 설정 유지
- 이전·다음 편, 강의 경계, 첫·마지막 편, 목차 검색, 브라우저 뒤로·앞으로
- 빠른 화질 변경, 느린 이전 요청 뒤의 작품 이동, 키보드·터치 이동
- 320px 세로 화면과 가로 화면, 고화질 확대, 이미지 404 후 다시 불러오기
- 전체 1,084개 이미지의 공개 응답 크기·SHA-256·브라우저 디코딩을 두 엔진에서 검사
- 일시적 503 발생 시 본문·미리보기 자동 복구, 재시도 소진 뒤 수동 복구, 작품 이동 시 이전 재시도 취소

PR과 `main`의 모든 푸시에서 원본 해시 검사와 브라우저 검사를 실행합니다. 브라우저 검사가 실패하면 Pages 아티팩트 업로드와 배포를 진행하지 않습니다. 배포 후에는 공개 URL에서 같은 기능 검사를 다시 수행하며, `build-info.json`의 커밋이 해당 배포와 일치하는지도 확인합니다. 공개 URL에서도 전체 이미지 디코딩을 검사해 배포된 파일의 누락을 확인합니다. 배포 후 검사가 실패하면 실행이 실패로 표시되며 자동 롤백은 하지 않습니다.

Actions의 `browser-report-build`, `browser-report-live` 아티팩트에 HTML 보고서와 화면 캡처를 14일 보관합니다. 실패 시 trace와 동영상도 남깁니다. 로컬 보고서는 `playwright-report/index.html`에서 확인할 수 있습니다.

기존 공개 사이트를 직접 검사하려면 다음처럼 실행합니다.

```sh
PLAYWRIGHT_BASE_URL=https://lawhlee.github.io/civil3_comics/ npm test
```

## 일시적인 이미지 전송 실패

본문과 미리보기는 이미지 오류 후 350ms, 1초 간격으로 최대 두 번 자동 재시도합니다. 본문은 계속 실패하면 기존 오류 안내와 수동 다시 불러오기를 표시합니다. 화질이나 작품을 바꾸면 이전 본문의 재시도를 취소합니다. 이미지 파일을 재압축하거나 다른 화질로 대체하지 않습니다.

전체 이미지 검사는 네트워크 오류·5xx·408·429만 최대 두 번 다시 요청하고, 복구된 요청도 보고서에 기록합니다. 404, 크기·해시 불일치, 디코딩 실패와 재시도 후에도 계속되는 오류는 실패 처리합니다. 정상 사용자 동작 검사에서는 예상하지 못한 HTTP/JavaScript 오류를 그대로 실패 처리합니다.
