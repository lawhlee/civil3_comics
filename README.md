# civil3_comics — 민법 판례 만화 서재

**공개 웹페이지: https://lawhlee.github.io/civil3_comics/**

민법 제6강부터 제10강까지 **271편**의 판례 만화입니다.

| 강의 | 편수 |
|---|---:|
| 제6강 공동소유와 명의신탁 | 91 |
| 제7강 담보물권과 저당권의 성립 | 23 |
| 제8강 저당권의 효력과 특수 저당권 | 89 |
| 제9강 유치권과 질권 | 31 |
| 제10강 가등기담보와 양도담보 | 37 |

강의별 목록, 제목·단원·판례번호 검색, 책갈피, 읽음 표시, 이어 읽기, 이전·다음 편 이동, 목차 및 이미지 확대를 지원합니다. 읽기 기록은 사용하는 브라우저에만 저장됩니다.

## 이미지와 업로드 방식

- 기존 교정 완료본의 **WebP 이미지 1,084개**를 그대로 보존합니다. 추가 손실 재압축이나 해상도 축소 없이 한글 글자와 교정 내용을 유지했습니다.
- 저용량 **480px**, 표준 **768px**, 고화질 **1024px**, 목록용 미리보기를 제공합니다. 기본값은 표준입니다. 작은 글씨는 고화질과 확대 기능으로 읽을 수 있습니다.
- 가장 큰 개별 이미지는 **599,882바이트**입니다. **Git LFS와 대용량 파일 저장 기능을 사용하지 않습니다.**
- 전체 정적 사이트를 추가 ZIP 압축한 **56개 묶음**으로 저장합니다. 각 묶음은 4MiB 이하이며, 전체는 **222,658,194바이트**입니다. WebP는 이미 압축되어 있으므로 ZIP의 추가 절감률은 작습니다.
- `asset-packs/manifest.json`에는 모든 ZIP 및 원본 파일의 크기와 SHA-256이 들어 있습니다. 빌드 시 경로, 중복, 크기, SHA-256, ZIP CRC 및 모든 활성 이미지 참조를 검사한 뒤에만 배포합니다.

## 로컬 실행

Python 3.10 이상만 필요합니다. 별도 설치나 서버 API가 없습니다.

```sh
python3 scripts/build-static.py
python3 -m http.server 8000 --directory dist
```

브라우저에서 `http://localhost:8000`을 엽니다. GitHub Pages는 같은 `dist`를 배포합니다. 파일 경로는 상대경로이므로 `/civil3_comics/` 하위 경로에서도 동작합니다.

## 수정과 검증

`dist`는 생성 결과라 Git에 넣지 않습니다. 웹페이지를 수정한 뒤 아래처럼 다시 묶습니다.

```sh
python3 scripts/pack-static.py dist --out asset-packs
python3 scripts/build-static.py
```

묶음 수가 줄었다면 사용하지 않는 `part-*.zip`을 제거한 뒤 커밋합니다. `main`의 `asset-packs` 또는 빌드 스크립트 변경은 기존 GitHub Actions를 통해 공개 웹페이지에 반영됩니다.
